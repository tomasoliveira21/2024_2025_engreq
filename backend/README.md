# ENG-REQ-API

## Overview
This API serves as a backend framework to handle operations for managing products, AMAPs, and users.
It supports authentication, role-based access control, and secure data storage using Sequelize and PostgreSQL.

## Technologies
- Node.js
- Express
- Sequelize
- PostgreSQL

## Installation

```
git clone https://github.com/your-repo-name/express-api.git  
cd express-api 

npm install
```

Create a .env file in the root directory:

```
DB_HOST=localhost  
DB_PORT=5432  
DB_USER=your_db_user  
DB_PASSWORD=your_db_password  
DB_NAME=your_database  
JWT_SECRET=your_jwt_secret  
SUPABASE_URL=your_supabase_url  
SUPABASE_KEY=your_supabase_key
```
Run the production server:
```
npm start  
```

## API

To consult the endpoints provided by the API, use the following link to consult the documentation:

http://localhost:3001/api-docs/
